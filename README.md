Project Overview
This project analyzes a social media engagement dataset containing 5,000 social media posts. The goal is to identify factors that influence engagement, understand user behavior, evaluate sentiment performance, and generate actionable insights.

Key Findings
Video posts achieved the highest engagement rate.
Food was the best-performing content category.
Brazil recorded the highest average engagement.
Users aged 45–60 showed the highest engagement.
Verified accounts outperformed non-verified accounts.
Mobile users generated the highest watch time.
Negative sentiment posts produced the highest engagement.
Posting-hour analysis was not possible due to missing timestamp information.

Conclusion
The analysis shows that content format, category, user demographics, account verification status, device usage, and sentiment significantly influence social media engagement. Video content, food-related topics, and mobile-first strategies demonstrated the strongest performance.
